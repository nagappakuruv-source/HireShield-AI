# JobShield AI

**An AI-Powered Suspicious Job and Internship Advertisement Analysis System**

## About the Project

JobShield AI is a machine learning-based application designed to analyze job and internship advertisements and identify potentially suspicious or misleading recruitment patterns.

The application uses Natural Language Processing (NLP) and Machine Learning techniques to examine advertisement text and provide a risk assessment.

## Key Technologies

- Python
- Streamlit
- Natural Language Processing (NLTK)
- Scikit-learn
- Pandas
- SQLite

## Core Objectives

- Analyze job and internship advertisement text.
- Identify potentially suspicious recruitment indicators.
- Apply NLP techniques for text preprocessing.
- Use machine learning for text classification.
- Present analysis results through an interactive interface.
- Store analysis history using SQLite.

## Project Structure

The project is organized into separate modules for the user interface, text preprocessing, machine learning, risk analysis, and database management.

## Disclaimer

JobShield AI provides automated risk assessments based on available advertisement information. Its results are indicative and should not be treated as definitive proof of fraud or legitimacy.
